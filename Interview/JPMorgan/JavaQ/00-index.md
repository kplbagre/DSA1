## 🏦 Interview Format (2024–2026)

```
Step 1: Online Assessment (HackerRank, 60 min)
        └── 2 questions: Easy-Medium DSA (arrays, intervals, strings)
        └── Sometimes 3 Qs: 2 OOP + 1 SQL

Step 2: SuperDay (3 rounds × 50–60 min, same day, each is elimination)
        ├── Round A: System Design OR DSA + Java Questions
        ├── Round B: Behavioral (conflict, ownership, ethics)
        └── Round C: Technical — Code Review + 1 DSA + Java depth

Step 3 (some roles): Hiring Manager / Team Matching Round
```

**Key pattern:** Every round is an **elimination round**. Round C almost always includes a **code review task** (a working prod snippet where you must suggest improvements).

## ⭐ Top 5 Topics by Frequency

1. **HashMap / ConcurrentHashMap internals** — asked in nearly every round
2. **Java Streams** (filter, map, reduce, collect) — OA + Technical round
3. **Multithreading** (thread safety, synchronized, executor service) — Technical round
4. **Arrays + Sliding Window / Intervals** — OA staple
5. **Code Review** — Round C constant
