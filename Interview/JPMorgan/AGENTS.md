## 📐 Additional Emoji Palette (JPMorgan notes only)

The following emojis are approved for use in JPMorgan problem-solution notes,
in addition to the universal palette defined in the root `AGENTS.md`:

| Emoji | Use for |
|-------|---------|
| `❓` | Clarifying questions section header |
| `🏗️` | LLD class diagram section header |
| `🔌` | Key interfaces section header |
| `⚙️` | Code-to-write / how-it-works section header |
| `🔁` | Concurrency section header |
| `🧨` | Java depth probes section header |
| `🏛️` | HLD decisions table header |
| `📡` | API design section header |
| `🛤️` | Happy + unhappy paths section header |
| `📐` | "What would you do differently?" section header |
| `📐` | Section order index |

**Why these exist:** The problem-solution note standard (`Round3/notes-standards-interview-problems.md`)
uses a 16-section structure that requires distinct emoji anchors for navigation.
The universal palette was designed for concept notes (fewer sections) and does not
have entries for interview-specific section types like "Java Depth Probes" or "API Design."
